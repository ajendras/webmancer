## [0.1.0] - 2026-11-22

### Added

- Natural Language — Describe complex multi-page flows in everyday English
- Page Context — Feed current URL or DOM snapshot for precise element targeting
- Playwright Output — Generates clean, best-practice TypeScript scripts with comments
- Chat Refinement — Iterate scripts through follow-up prompts in a conversational UI
- Visual Simulator — Animated step-by-step preview of every click, type and navigation
- Automation Gallery — Save, tag and reuse scripts with full-text search
- One-click Export — Copy script, download as test file or shareable recipe
- Robust Selectors — AI prefers role, text, test-id and aria labels over brittle XPaths
